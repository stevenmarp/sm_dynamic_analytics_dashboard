Dynamic Analytics Dashboard
===========================

Create dynamic dashboards from Odoo models or safe read-only SQL queries.

Features
--------

* Dashboard builder
* KPI, bar, line, pie, and table blocks
* Model-based analytics
* Read-only SQL analytics
* Domain, measure, group by, aggregate, and limit controls
* Dashboard JSON export
* Per-dashboard user sharing
* Company-aware dashboard records
* Lightweight OWL frontend action

How to Use
----------

1. Install the module.
2. Open Analytics Dashboard.
3. Create an Analysis from an Odoo model or SQL query.
4. Create a Dashboard.
5. Add Blocks linked to Analyses.
6. Click Open Dashboard.
